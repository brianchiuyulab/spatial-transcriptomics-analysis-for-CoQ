# Figure guide

Each result is exported as one independent PNG at 300 dpi.

| File | Purpose | Suggested placement |
|---|---|---|
| `Fig01_QC.png` | Published bead filtering and retained-bead metrics | Supplementary |
| `Fig02_Young_celltype_map.png` | Young section, dominant author-derived cell2location label | Supplementary or paired main figure |
| `Fig03_Geriatric_celltype_map.png` | Geriatric section, dominant author-derived cell2location label | Supplementary or paired main figure |
| `Fig04_Young_Coq8a_map.png` | Young Coq8a, Fusing Myocytes, and MuSC spatial map | Main candidate |
| `Fig05_Geriatric_Coq8a_map.png` | Geriatric Coq8a, Fusing Myocytes, and MuSC spatial map | Main candidate |
| `Fig06_Coq8a_celltype_association.png` | Forest plot of cell-label associations with Coq8a-positive injury beads; odds ratios, 95% CIs, and clearly marked BH-adjusted significance | Main candidate |
| `Fig07_Fusing_marker_audit.png` | Descriptive marker dot plot for Fusing Myocytes-labelled versus other injury regions | Supplementary |
| `Fig08_Coq8a_fusion_neighborhood.png` | Random-foci neighborhood enrichment across radii; significant radii are marked by magenta stars | Main candidate |
| `Fig09_Coq8a_injury_vs_outside.png` | Global injury-zone comparison | Supplementary |

The cell-type maps are separate files, and the young and geriatric Coq8a maps are separate files. No composite figure is generated by the analysis code.

The spatial maps are new Matplotlib renderings produced by this release. They are not screenshots or unchanged exports from the authors' notebook. Coordinates, injury labels, and q05-derived cell2location proportions come from the authors' deposited processed objects; gene counts come from GEO. *Coq8a*-positive means raw *Coq8a* count ≥ 1 and is not percentile-based.

## Suggested manuscript assembly

Main-figure candidates are Fig04, Fig05, Fig06, and Fig08. Fig01–03, Fig07, and Fig09 provide quality-control, annotation, marker-profile, and tissue-region context suitable for supplementary figures. The release keeps every panel as an independent PNG so the final journal layout can be assembled without extracting images from a contact sheet.
